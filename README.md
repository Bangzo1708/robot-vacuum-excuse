The funniest excuse a robot vacuum can give for missing a spot — one line, at most 120 characters. Three hand-written candidate lines, each from a different angle, are scored against the judge's own criteria in priority order (an excuse for the missed spot first, a real joke second, the vacuum's own voice third, vacuum-world humour fourth, landing in a single line fifth), and the strongest one is written to `/output/entry.txt`. Fully deterministic: no randomness, no clock, no network, no file reads.

## Run it

```sh
python3 main.py
```
